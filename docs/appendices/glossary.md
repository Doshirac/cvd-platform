# Glossary

## Key Terms

| Term | Definition |
|------|------------|
| CVD | Cardiovascular Disease - core domain of the platform |
| Disease card | Structured disease entry (name, symptoms, prevention) |
| Symptom | Patient-reported/observed manifestation |
| Risk factor | Factor increasing disease probability |
| Protective factor | Factor reducing disease probability |
| Locale | Language support (EN/RU) |
| MVP | Minimum Viable Product |

| Acronym | Meaning |

| ICD-10 | International Classification of Diseases |
| SNOMED | Clinical terminology standard |

| GDPR | General Data Protection Regulation |
