# Stakeholders & Users

## Target Audience

| User Group | Description | Primary Needs |
|------------|-------------|---------------|
| Clinicians / Medical students | Structured CVD information users | Fast lookup, consistent terminology, references |
| Educators / Researchers | Teaching materials users | Reliable citations, exportable summaries |
| Analysts / Public health readers | Data exploration users | Analytics visuals, source transparency |

## Stakeholder Analysis Matrix

| Stakeholder | Role | Interest | Influence | Engagement |
|-------------|------|----------|-----------|------------|
| Product Owner & Engineer | Implementer | High | High | Weekly milestones |
| Academic Supervisor | Evaluator | Medium | High | Control checkpoints |
| Clinical Consultant | Content reviewer | High | High | 2-3 review sessions |
| End Users | Platform users | High | Medium | Usability tests |
| Data Source Owners | Data providers | Medium | Medium | License compliance |

## Stakeholder Expectations

- Accuracy and reliable references
- Consistent terminology and structure
- Clear symptom/risk-factor separation
- Source transparency (provenance + last updated)
- Academic methodological rigor
